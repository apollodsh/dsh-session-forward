# 会话转发：零安装分享方案

**我**

帮我看看这段转发文件的结构对不对？顺便说说怎么让接收方不用装插件。

**助手**

结构没问题：format 是 dsh-session-forward，messages 里每条都有 role / text。

零安装的做法是把同一段对话另外渲染成一个完全自包含的 HTML 页面——内联样式、内联脚本、不引用任何外部资源，对方双击就能读。

**我**

那还能在 DSH 里接着聊吗？

**助手**

可以：网页底部有一个「复制全文（Markdown）」按钮，对方复制后粘进自己的 DSH 对话框，模型就能看到完整历史，接着往下聊。

如果想让它直接出现在对方 DSH 的会话列表里，那还是得两边都装这个插件，用 .dshchat 导入。
